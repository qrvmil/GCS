# Online GCS

Online GCS — исследовательская библиотека на Python 3.12 для планирования движений
манипулятора. Стандартный запуск оценивает baseline RRT* для каждого запроса и
baseline TrajOpt при наличии пути, а затем проверяет Graph of Convex Sets (GCS). При
недостаточном покрытии путь RRT* даёт ключевые точки для новых областей IRIS и
повторного GCS. Поэтому baseline добавляет время даже при успехе GCS, а TrajOpt
зависит от наличия совместимого solver.

## Границы релиза

Версия `0.1.0` — исследовательский релиз до 1.0. Он поддерживает Python 3.12 и не
включает в публичное дерево отчёты, notebook, сырые результаты экспериментов, логи
и сгенерированные данные. Подробности релиза приведены в
[журнале изменений](https://github.com/qrvmil/GCS/blob/main/CHANGELOG.md).
