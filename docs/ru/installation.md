# Установка

## Требования

- Python 3.12 (релиз `0.1.0` не заявляет поддержку других версий).
- Платформа, поддерживаемая выбранным wheel Drake и его зависимостями.
- Доступ к сети при первом запуске, если Drake или `manipulation` потребуются модели.

Создайте изолированное окружение из корня репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

## Установка библиотеки

Для работы с исходным кодом удобна editable-установка:

```bash
python -m pip install -e .
```

Убедитесь, что пакет и CLI доступны:

```bash
python -c "import online_gcs; print(online_gcs.__version__)"
online-gcs --help
python -m online_gcs --help
```

## Дополнительные зависимости

Для участия в разработке установите инструменты разработки и документации:

```bash
python -m pip install -e '.[dev,docs]'
```

Дополнение `experiments` устанавливает библиотеки для графиков и анализа таблиц;
оно не требуется библиотеке, CLI или примерам.

```bash
python -m pip install -e '.[experiments]'
```

## Solver и модели

IRIS и GCS используют solver, доступные в Drake. Для оптимизации траектории также
необходим совместимый solver математических программ. Отсутствие solver — свойство
окружения, а не доказательство отсутствия пути. Диагностика приведена в разделе
[«Решение проблем»](troubleshooting.md).
