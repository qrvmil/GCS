# Решение проблем

## Не найден импорт или команда

Проверьте Python 3.12 и установите исходный код в активное окружение:

```bash
python --version
python -m pip install -e .
python -c "import online_gcs; print(online_gcs.__version__)"
python -m online_gcs --help
```

Если `python -m online_gcs` работает, а `online-gcs` — нет, повторно активируйте
виртуальное окружение и убедитесь, что его каталог `bin` присутствует в `PATH`.

## Загрузка моделей или сборка сцены

При первом запуске Drake/`manipulation` могут загрузить модели. Проверьте доступ к
сети и повторите запуск после окончания загрузки. В сообщении об ошибке сборки сцены
укажите сцену, платформу, версию Drake и полный текст исключения.

## Медленное построение IRIS

IRIS может требовать значительных вычислений; время зависит от геометрии сцены,
положения seed и поведения solver. Начните с одного запроса и двух ключевых точек:

```bash
online-gcs --scene SINGLE_SHELF --iterations 1 --keypoints 2 --prune-interval 0 --seed 42
```

Не завершайте исправный процесс только потому, что он работает дольше другой
машины. При подготовке воспроизводимого bug report включите `--verbose`.

## Solver недоступен

Оптимизация траектории зависит от совместимого solver в установленном окружении
Drake. Запустите обычный онлайн-режим, чтобы отличить проблему solver в `--opt-only`
от сборки сцены или RRT*. Приложите к issue точный текст ошибки возможностей;
установка другого solver может потребовать отдельной лицензии.

## Meshcat не отображается

Запустите программу с `--visualize`, откройте напечатанный URL в браузере на той же
машине и не завершайте процесс Python. Для удалённых, контейнерных или защищённых
firewall окружений может понадобиться port forwarding, который проект автоматически
не настраивает.

## Некорректные аргументы

`iterations` должно быть не меньше 1, `keypoints` — не меньше 2, pruning —
неотрицательным, число workers и путей — не меньше 1, а скорость анимации —
положительной. Перед issue откройте встроенную справку:

```bash
online-gcs --help
```
